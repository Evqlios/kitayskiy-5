Что делать дальше, по важности (то, что подтверждено):
1. Экраны заданий: большие пустые области под вопросом, мелкие иероглифы в вариантах, почти невидимая полоса прогресса; на ноутбуке контент в левой половине (решение владельца из `dev/DESIGN.md`, п. 5).
2. Сборка предложения принимает только заранее заданные порядки (`acc`): верный, но непредусмотренный порядок засчитывается ошибкой; вторая попытка тоже.
3. Повторение грамматики идёт только через ошибки (`gramDue66`); верно решённые вопросы в повторение не попадают; нет отдельного экрана «Повторение».
4. Говорение («Скажи вслух», вкладка «Голос» только в Chrome на Android) и письмо не проверяются; аудирование на синтезированных голосах.
5. «Путь»: много вводных текстов перед первым заданием для новичка; пустая «Статистика» показывает шесть пустых строк.
6. Ответы СГУ выведены, а не списаны (ключей нет); единственный канал исправления — кнопка «Нашли ошибку?», жалобы читаются только в консоли Firebase.
7. Рейтинг защищён клиентом и правилами Firestore (App Check выключен); один файл 2,5 МБ без исходников сборки; `localStorage` при нехватке места молча удаляет снимки.
