## Обновление 13 (27.11, Beta, сборка 10): озвучка знаков и слов (выложено по «выкладывай»)
- Жалобы Ильи: 您好/你好 не различить, 张 звучит неправильно, «лишнее слово», кривая озвучка. Проверка: все 1222 клипа мужского голоса сравнены с заново сгенерированными — совпадают, то есть пакеты собраны верно, ошибка в самом чтении синтезатором коротких текстов. Поэтому: `dev/tools/voice_fix.py` перебирает способы записи (знак; знак+«。»; «знак，знак。» со вторым; «。» на −15%; слоги через запятую; три повтора; «！»), каждый результат распознаёт офлайн (sherpa-onnx paraformer-zh-small, берётся с github.com/k2-fsa/sherpa-onnx/releases/tag/asr-models) и выбирает тот, где пиньинь с тонами (pypinyin) совпал с ожидаемым. `voice_tailfix.py` вырезает слог из слова (长 из 校长, 乐 из 快乐, 兴 из 高兴, 的 из 我的) с подбором точки по распознаванию. `voice_select.py` заменяет старый клип только если новый лучше по той же проверке; клипы заданий с тем же текстом получают копии. `voice_pack.py --replace` дописывает новые клипы в конец и перенаправляет индекс (старые байты остаются, смещения других клипов не меняются).
